# gasanovdoc.ru — сайт нейрохирурга Тимура Гасанова

Статический сайт на [Astro](https://astro.build). Хостинг — VPS в РФ (Reg.ru), домен gasanovdoc.ru.

## Команды
- `npm install` — установить зависимости
- `npm run dev` — локальный просмотр (http://localhost:4321)
- `npm run build` — сборка в папку `dist/`

## Структура
- `src/pages/` — страницы (адрес = путь к файлу)
- `src/layouts/Base.astro` — общий каркас: шапка, подвал, SEO-теги
- `src/styles/global.css` — дизайн-система: цвета, шрифты, компоненты
- `public/media/` — фото, видео, снимки случаев (обезличенные)
- `public/js/home.js` — интерактив главной (карусель случаев, форма)
- `content-source/` — экспорт Telegram-канала, источник для статей

## Правила
- ТЗ и структура — в проекте Claude «AI SMM (common)»: «ТЗ на сайт», «Структура сайта», «Контент сайта из блога».
- Медицинские тексты — 38-ФЗ: без гарантий, «лучший», «№1»; слово «консультация» на сайте не используем.
- Секреты (токен бота, пароль почты) — только в `.env` на сервере, не в репозитории.
