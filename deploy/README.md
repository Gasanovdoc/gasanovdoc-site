# Запуск сайта gasanovdoc.ru на сервере Reg.ru

## 1. Купить сервер
Reg.ru → Облачные серверы (VPS) → Ubuntu 24.04, 1 ядро / 1–2 ГБ памяти / 15+ ГБ диска, регион — Москва.
После создания в письме и в панели будут **IP-адрес** и **пароль root**.

## 2. Направить домен на сервер
Reg.ru → Домены → gasanovdoc.ru → DNS-серверы и управление зоной:
- запись **A**: `@` → IP сервера
- запись **A**: `www` → IP сервера

Обновление DNS занимает от 15 минут до нескольких часов.

## 3. Подготовить данные (не присылать в чат!)
- **Пароль приложения Яндекс Почты:** id.yandex.ru → Безопасность → Пароли приложений → «Почта». В настройках Яндекс Почты включить доступ по протоколу IMAP/SMTP («Почтовые программы»).
- **Токен бота:** @BotFather → /mybots → бот → API Token → Revoke (выпустить новый, старый засвечен).

## 4. Запустить настройку
Подключиться к серверу (на Mac/Windows в терминале):
```
ssh root@IP_СЕРВЕРА
```
и выполнить:
```
apt-get update && apt-get install -y git
git clone https://github.com/Gasanovdoc/gasanovdoc-site.git /var/www/gasanovdoc
bash /var/www/gasanovdoc/deploy/setup.sh
```
Скрипт сам установит всё нужное, спросит почту, пароль приложения, токен бота, предложит написать боту /start и получит HTTPS-сертификат. В конце напишет «приём заявок работает».

> Если репозиторий приватный, git попросит логин и токен GitHub. Проще сделать репозиторий публичным: в нём нет секретов, только код сайта.

## 5. Обновления
После каждого изменения сайта:
```
bash /var/www/gasanovdoc/deploy/update.sh
```

## Где что лежит
- сайт: `/var/www/gasanovdoc/dist`
- заявки: `/var/lib/gasanovdoc/zayavki.jsonl` (доступ только у root и службы), копии — `/var/backups/gasanovdoc`, 30 дней
- секреты: `/etc/gasanovdoc/api.env`
- журнал службы заявок: `journalctl -u gasanovdoc-api -n 50`

## Перед запуском
`npm run build && npm run prelaunch` — проверяет, что на страницах не осталось пометок [ПРОВЕРИТЬ] и незаполненного адреса в политике.
