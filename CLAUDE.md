# CLAUDE.md — сайт gasanovdoc.ru

Этот файл читает Claude в каждом новом диалоге, где подключён репозиторий. Владелец — нейрохирург Тимур Гасанов. Общение на русском, на «вы», простыми словами: Тимур не программист.

Полные правила, история решений и справка по серверу — в документах проекта Claude: «Сайт — решения, правила и история», «Сайт — запуск и обслуживание». Прочитай их перед работой.

## Начало работы в новом диалоге
1. Репозиторий: `git clone` в `/home/claude/gasanovdoc-site` (если ещё не склонирован), затем `npm ci`.
2. Посмотри ветки: `git fetch && git branch -r`. Черновики живут в отдельных ветках (например, `content/nerves-en` — статьи о нервах и английская версия, ждут вычитки Тимура).
3. Сборка и проверка: `npm run build && npm run prelaunch`.

## Публикация — главное правило
- Изменения сайта — только в отдельной ветке (`design/…`, `content/…`, `seo/…`). Запушить ветку можно.
- В `main` — **только после слова Тимура «публикуем»** (merge `--no-ff`, push).
- Сервер сам каждые 2 минуты проверяет `main` и обновляет сайт (таймер `gasanovdoc-autoupdate`). Если Тимур хочет обновить руками, дай ему команду для терминала сервера: `bash /var/www/gasanovdoc/deploy/update.sh`.
- Меняй только то, о чём просили.

## Показ черновика Тимуру
- Тимур смотрит черновики кликабельной HTML-страницей, а не скриншотами.
- После `npm run build`: `python3 tools/preview/bundle.py <папка>` — делает копию сайта с относительными путями и печатает список файлов. Опубликуй `<папка>/index.html` как Artifact с `root=<папка>` и этим списком в `files`. Обновляй тот же артефакт в пределах диалога.
- Для своей проверки вёрстки: `node tools/preview/shot.js <папка> '<селектор>' out.png [ширина]` (ширина 390 — телефон).

## Иллюстрации
- Реалистичные, в стиле МРТ/ангиографии. Генераторы: `tools/mri/` (base.py — срезы атласа MNI ICBM152 из пакета nilearn; tumors.py, other.py, sag.py, dsa.py). Нужны `pip install --break-system-packages nilearn nibabel scipy pillow`.
- На сайт: `public/media/schemes/*.webp`, разметка через `src/components/MriFig.astro` и `src/components/schemes/*`. В подписи — источник и «не снимок пациента».
- Новые иллюстрации, фото и видео — сначала показать Тимуру.

## Фото и видео с компьютера Тимура
- Доступны, только если диалог связан с его Mac (приложение Claude на компьютере) и подключена папка `/Volumes`. Внешний диск — `/Volumes/Disk D`.
- Исходники не менять и не удалять. Рабочие файлы — в `/Volumes/Disk D/_Claude_для_сайта/`.
- В названиях видео операций есть фамилии пациентов: на сайт — только переименованные и обезличенные нарезки.

## Коммиты
- Сообщение коммита — по-русски, коротко, что изменилось для пациента или Тимура.

## Нельзя
- Запрашивать или записывать пароли, токены, ключи. Секреты — только в `/etc/gasanovdoc/api.env` на сервере, Тимур вписывает их сам.
- Публиковать без «публикуем».
- Слово «консультация», название клиники, гарантии и «лучший» (38-ФЗ), узнаваемые данные пациентов.
